# 语言语法
twinBASIC 对 VBx 语言语法引入了众多增强功能，包括新数据类型、改进的类型系统和现代编程结构。

## 主题

- [别名类型](Alias-Types) - 别名类型，类似于 C 中的 **typedef** 和 C++ 中的 **using**
- [数据类型](Data-Types) - 新数据类型（**LongPtr**、**LongLong**、**Decimal**）
- [接口和 Coclass](Interfaces-CoClasses) - 原生接口和 coclass 定义
- [继承](Inheritance) - **Implements Via** 和 **Inherits** 关键字
- [委托](Delegates) - 函数指针，也称为委托
- [泛型](Generics) - 泛型类型支持
- [重载](Overloading) - 方法重载功能
- [操作符](Operators) - 新操作符和语法
- [字面量](Literals) - 二进制字面量和数字分组
- [类型推断](Type-Inference) - **As Any** 类型推断
- [指针](Pointers) - 增强的指针功能
- [UDT 增强功能](UDTs) - 用户定义类型改进
- [循环控制](Loop-Control) - **Continue ...** 和 **Exit While**
- [返回语法](Return) - 现代 **Return** 语句
- [内联初始化](Inline-Initialization) - 变量初始化
- [处理程序方法](Handlers) - **Handles** 和 **Implements** 语法
- [模块组织](Module-Organization) - 代码放置灵活性
- [注释](Comments) - 新代码注释语法
