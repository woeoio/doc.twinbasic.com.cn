# 项目配置

twinBASIC 提供各种项目配置选项和新项目类型以满足不同开发需求。

## 主题

- [项目类型](/official/Features/Project-Configuration/Project-Types) - 标准 DLL、控制台、服务和内核驱动
- [编译器选项](/official/Features/Project-Configuration/Compiler-Options) - 入口点、IAT 放置等
- [ActiveX 注册选项](/official/Features/Project-Configuration/ActiveX-Registration) - ActiveX 项目的注册设置
