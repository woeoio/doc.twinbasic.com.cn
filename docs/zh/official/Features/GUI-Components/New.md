# 新控件
twinBASIC 引入了几个新控件来增强您的应用程序。

## 二维码控件

![image](../Images/54ed49d8-b434-45e3-9e63-a1fe75cdf814.png)

使用原生控件轻松显示自定义二维码。

## 多帧控件

![image](../Images/4ad9c774-b31d-47d3-9963-6d99ac4f37bb.png)

此控件允许您在其中创建多个框架，其大小指定为百分比，这样当控件调整大小时，其中的框架按比例扩展。有关详细信息和视频演示，Mike Wolfe 的 twinBASIC 每周更新[发布时对此进行了介绍](https://nolongerset.com/twinbasic-update-april-29-2025/#experimental-multi-frame-control)。

结合锚定和停靠，这允许以可视化方式设计功能高度复杂和功能强大的布局，而无需编写任何处理调整大小的代码。

## 复选标记控件

![image](../Images/5fc60b7b-4f54-445c-8504-451019b7ec55.png)

主要面向报表，但也可在窗体和用户控件中使用，复选标记控件提供可缩放的复选组件，而在普通复选框控件中这是固定为单一大小的。
