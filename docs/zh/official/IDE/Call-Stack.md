# 调用堆栈

![Call Stack](Images/CallStack.png "Call Stack")

调用堆栈面板在调试会话中列出当前执行点的活动过程调用链，最近的调用位于顶部。点击列表中的条目可跳转到编辑器中对应的调用位置。
