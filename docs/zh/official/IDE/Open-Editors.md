# 打开的编辑器

未打开项目时此面板为空。

![Open Editors](Images/OpenEditors.png "Open Editors")

打开项目后，将列出当前在[编辑器](/official/IDE/Editor)中打开的文件。

![Open Editors](Images/OpenEditors_1.png "Open Editors")

点击列表中的文件可在编辑器中将其聚焦。
