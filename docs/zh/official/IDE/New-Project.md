# 最近

如果从未打开过项目，或已移除所有项目，此选项卡将为空白。

![Recent](Images/New_Project_Recent_1.png "Recent")

将显示最近项目的列表，列表会根据项目数量自动调整大小。

![Recent](Images/New_Project_Recent_2.png "Recent")

_移除路径_

点击 X 可从列表中移除。
