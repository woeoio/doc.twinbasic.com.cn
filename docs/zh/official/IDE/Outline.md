# 大纲

大纲面板显示活动源文件中声明的结构概览——模块、类、过程和属性。

未打开项目时此面板为空。

![Outline](Images/Outline.png "Outline")

打开项目后将列出 `模块`/`类` 等。

![Outline](Images/Outline_1.png "Outline")

点击条目可跳转到代码文件中的对应位置。
