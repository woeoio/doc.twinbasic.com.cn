# 监视

未打开项目时此面板为空。

![Watches](Images/Watches.png "Watches")

打开项目后会有其他按钮可用。

![Watches](Images/Watches_1.png "Watches")

要添加新的监视，点击 ![Add](Images/Add.png "Add") 并输入要监视的"表达式"。

![Watches](Images/Watches_2.png "Watches")

可以使用清除按钮 ![Clear](Images/Clear.png "Clear") 移除任意监视。
