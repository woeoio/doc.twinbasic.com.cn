# 监视

未打开项目时此面板为空。

![监视](Images/Watches.png "监视")

打开项目后会有其他按钮可用。

![监视](Images/Watches_1.png "监视")

要添加新的监视，点击 ![添加](Images/Add.png "添加") 并输入要监视的"表达式"。

![监视](Images/Watches_2.png "监视")

可以使用清除按钮 ![清除](Images/Clear.png "清除") 移除任意监视。
