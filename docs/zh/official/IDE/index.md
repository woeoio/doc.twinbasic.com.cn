# The twinBASIC IDE

![IDE](Images/IDE.png "IDE")

The IDE consists of several fixed panes and tool windows. The [**Project Explorer**](/official/IDE/Project-Explorer) shows the file tree of the open project; the [**Editor**](/official/IDE/Editor) is the main code and designer surface; the [**Properties**](/official/IDE/Properties) pane shows and edits properties for the selected item; the [**Toolbox**](/official/IDE/Toolbox) lists the controls available to drop onto a form.

The debug tool windows --- [**Call Stack**](/official/IDE/Call-Stack), [**Watches**](/official/IDE/Watches), [**Variables**](/official/IDE/Variables), [**Debug Console**](/official/IDE/Debug-Console), [**Diagnostics**](/official/IDE/Diagnostics), [**Outline**](/official/IDE/Outline), and [**Memory**](/official/IDE/Memory) --- open during a debug session.

The [**tbForm**](/official/IDE/tbForm) and [**tbReport**](/official/IDE/tbReport) designers open when a form or report file is selected in the Project Explorer. Third-party and community [**addins**](/official/IDE/AddIns/) extend the IDE with additional commands and tool windows.
