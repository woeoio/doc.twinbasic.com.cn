![Editor](Images/Editor.png "Editor")

## 选项

- 显示代码折叠
  - 从不
  - *悬停时*
  - 始终

- 渲染空白
  - 全部
  - *无*
  - 边界
  - 选区
  - 尾部

- 字体大小
  - 8px
  - ...
  - *13px*
  - ...
  - 30px
- 显示导航栏
  - 上方
  - 下方
  - 无
- ✔ 显示缩进参考线
- ✔ 显示行号
- 代码提示始终可见
- 粘性滚动
- ✔ 显示缩略图
- 悬停时显示高级信息
- 显示单行标签页
- ✔ 自动美化代码
- ✔ 显示 CodeLens 运行过程
