# 历史记录

当项目未打开时，这将为空。

![历史记录](Images/History.png "历史记录")

一旦您打开项目

![历史记录](Images/History_1.png "历史记录")

如果您悬停在项目上，它将显示文件的路径。

![历史记录](Images/History_2.png "历史记录")

如果是代码文件（即`.twin`），它将显示"行: #"。

![历史记录](Images/History_3.png "历史记录")

您也可以点击项目来打开它。
