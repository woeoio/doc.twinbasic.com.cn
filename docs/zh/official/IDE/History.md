# 历史记录

未打开项目时此面板为空。

![History](Images/History.png "History")

打开项目后

![History](Images/History_1.png "History")

将鼠标悬停在条目上会显示文件路径。

![History](Images/History_2.png "History")

如果是代码文件（如 `.twin`），还会显示"行号: #"。

![History](Images/History_3.png "History")

点击条目即可打开对应文件。
