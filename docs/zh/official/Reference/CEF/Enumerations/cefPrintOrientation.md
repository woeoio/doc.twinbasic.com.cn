# cefPrintOrientation

Page orientation passed to [**PrintToPdf**](/official/Reference/CEF/CefBrowser/#printtopdf) when writing the current document to a PDF file.

| Constant | Value | Description |
|----------|-------|-------------|
| **cefPrintPortrait** | 0 | Default --- pages are laid out with the long side vertical. |
| **cefPrintLandscape** | 1 | Pages are laid out with the long side horizontal. |
