# cefPrintOrientation

将当前文档写入PDF文件时传递给 [**PrintToPdf**](/official/Reference/CEF/CefBrowser/#printtopdf) 的页面方向。

| 常量 | 值 | 说明 |
|----------|-------|-------------|
| **cefPrintPortrait** | 0 | 默认——页面以长边垂直方向排版。 |
| **cefPrintLandscape** | 1 | 页面以长边水平方向排版。 |
