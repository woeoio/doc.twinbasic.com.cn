# Customtate
::: info
名称 **Customtate** 看起来是 "CustomState" 的拼写错误，保留自包的早期草稿。该枚举未被八个具体 `Waynes…` 控件引用；[**WaynesForm**](/official/Reference/CustomControls/WaynesForm/) 的实际最小化/正常/最大化状态由并行的 [**WindowState**](/official/Reference/CustomControls/Enumerations/WindowState) 枚举控制，其成员相同。将 **Customtate** 视为保留。
:::

与 [**WindowState**](/official/Reference/CustomControls/Enumerations/WindowState) 具有相同三个成员的保留枚举。定义在 **CustomControls DESIGNER** 库的 `Module Constants` 中，以 **Public** 导出，但在包内未被使用。

| 常量 | 值 | 说明 |
|------|----|------|
| **tbNormal** | 0 | 与 [**WindowState.tbNormal**](/official/Reference/CustomControls/Enumerations/WindowState#tbNormal) 值相同。 |
| **tbMinimized** | 1 | 与 [**WindowState.tbMinimized**](/official/Reference/CustomControls/Enumerations/WindowState#tbMinimized) 值相同。 |
| **tbMaximized** | 2 | 与 [**WindowState.tbMaximized**](/official/Reference/CustomControls/Enumerations/WindowState#tbMaximized) 值相同。 |
