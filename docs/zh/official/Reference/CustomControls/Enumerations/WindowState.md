# WindowState
[**WaynesForm**](/official/Reference/CustomControls/WaynesForm/) 的窗口状态——最小化、恢复正常大小或最大化填满监视器。由 [**WindowsFormOptions.WindowState**](/official/Reference/CustomControls/WaynesForm/WindowsFormOptions#windowstate) 使用；在窗体首次显示时生效一次。

| 常量 | 值 | 说明 |
|------|----|------|
| **tbNormal** | 0 | 窗口以设计时大小显示。新构造的 [**WindowsFormOptions**](/official/Reference/CustomControls/WaynesForm/WindowsFormOptions) 的默认值。 |
| **tbMinimized** | 1 | 窗口首次显示时最小化到任务栏。 |
| **tbMaximized** | 2 | 窗口首次显示时最大化填满监视器。 |
