# VbCompareMethod

Text comparison modes used by string functions such as [**InStr**](/official/Reference/VBA/Strings/InStr), [**InStrRev**](/official/Reference/VBA/Strings/InStrRev), [**Replace**](/official/Reference/VBA/Strings/Replace), [**StrComp**](/official/Reference/VBA/Strings/StrComp), [**Filter**](/official/Reference/VBA/Strings/Filter), and [**Split**](/official/Reference/VBA/Strings/Split).

| Constant | Value | Description |
|----------|-------|-------------|
| **vbBinaryCompare** | 0 | Performs a binary comparison. |
| **vbTextCompare** | 1 | Performs a textual comparison. |
| **vbDatabaseCompare** | 2 | For Microsoft Access (Windows only), performs a comparison based on information contained in the database. |
