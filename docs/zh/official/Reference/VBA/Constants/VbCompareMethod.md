# VbCompareMethod

字符串函数（如 [**InStr**](/official/Reference/VBA/Strings/InStr)、[**InStrRev**](/official/Reference/VBA/Strings/InStrRev)、[**Replace**](/official/Reference/VBA/Strings/Replace)、[**StrComp**](/official/Reference/VBA/Strings/StrComp)、[**Filter**](/official/Reference/VBA/Strings/Filter) 和 [**Split**](/official/Reference/VBA/Strings/Split)）使用的文本比较模式。

| 常量 | 值 | 描述 |
|------|-----|------|
| **vbBinaryCompare** | 0 | 执行二进制比较。 |
| **vbTextCompare** | 1 | 执行文本比较。 |
| **vbDatabaseCompare** | 2 | 仅限 Microsoft Access (Windows)，根据数据库中的信息执行比较。 |
