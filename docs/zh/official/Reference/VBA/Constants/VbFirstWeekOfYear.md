# VbFirstWeekOfYear

日期函数（如 [**DateDiff**](/official/Reference/VBA/DateTime/DateDiff)、[**DatePart**](/official/Reference/VBA/DateTime/DatePart) 和 [**Weekday**](/official/Reference/VBA/DateTime/Weekday)）用作 *firstweekofyear* 参数的年份首周选择器。

| 常量 | 值 | 描述 |
|------|-----|------|
| **vbUseSystem** | 0 | 使用系统区域设置中的设置。 |
| **vbFirstJan1** | 1 | 从包含 1 月 1 日的周开始（默认）。 |
| **vbFirstFourDays** | 2 | 从新年中至少有四天的第一周开始。 |
| **vbFirstFullWeek** | 3 | 从一年的第一个完整周开始。 |
