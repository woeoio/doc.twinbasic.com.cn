# VbAppWinStyle

[**Shell**](/official/Reference/VBA/Interaction/Shell) 函数的 *windowstyle* 参数所使用的窗口样式值。

| 常量 | 值 | 描述 |
|------|-----|------|
| **vbHide** | 0 | 窗口被隐藏，焦点传递给隐藏的窗口。 |
| **vbNormalFocus** | 1 | 窗口获得焦点，并恢复到原始大小和位置。 |
| **vbMinimizedFocus** | 2 | 窗口显示为图标并获得焦点。 |
| **vbMaximizedFocus** | 3 | 窗口最大化并获得焦点。 |
| **vbNormalNoFocus** | 4 | 窗口恢复到最近的大小和位置。当前活动窗口保持活动。 |
| **vbMinimizedNoFocus** | 6 | 窗口显示为图标。当前活动窗口保持活动。 |
