# VbDayOfWeek

日期函数（如 [**DateAdd**](/official/Reference/VBA/DateTime/DateAdd)、[**DateDiff**](/official/Reference/VBA/DateTime/DateDiff)、[**DatePart**](/official/Reference/VBA/DateTime/DatePart) 和 [**Weekday**](/official/Reference/VBA/DateTime/Weekday)）用作 *firstdayofweek* 参数及其返回值的星期常量。

| 常量 | 值 | 描述 |
|------|-----|------|
| **vbUseSystemDayOfWeek** | 0 | 使用系统区域设置中指定的星期。 |
| **vbSunday** | 1 | 星期日（默认）。 |
| **vbMonday** | 2 | 星期一。 |
| **vbTuesday** | 3 | 星期二。 |
| **vbWednesday** | 4 | 星期三。 |
| **vbThursday** | 5 | 星期四。 |
| **vbFriday** | 6 | 星期五。 |
| **vbSaturday** | 7 | 星期六。 |
