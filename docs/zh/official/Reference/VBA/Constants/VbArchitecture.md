# VbArchitecture

Processor architecture values returned by the [**ProcessorArchitecture**](/official/Reference/VBA/Compilation/ProcessorArchitecture) function.

| Constant | Value | Description |
|----------|-------|-------------|
| **vbArchWin32** | 0 | 32-bit (x86) Windows. |
| **vbArchWin64** | 1 | 64-bit (AMD64) Windows. |
