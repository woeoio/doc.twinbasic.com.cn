# VbArchitecture

[**ProcessorArchitecture**](/official/Reference/VBA/Compilation/ProcessorArchitecture) 函数返回的处理器架构值。

| 常量 | 值 | 描述 |
|------|-----|------|
| **vbArchWin32** | 0 | 32 位 (x86) Windows。 |
| **vbArchWin64** | 1 | 64 位 (AMD64) Windows。 |
