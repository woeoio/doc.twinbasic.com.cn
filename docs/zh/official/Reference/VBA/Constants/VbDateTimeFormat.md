# VbDateTimeFormat

[**FormatDateTime**](/official/Reference/VBA/Strings/FormatDateTime) 函数的格式代码。

| 常量 | 值 | 描述 |
|------|-----|------|
| **vbGeneralDate** | 0 | 显示日期和/或时间。对于实数，显示日期和时间；如果没有小数部分，仅显示日期；如果没有整数部分，仅显示时间。日期和时间的显示由系统设置决定。 |
| **vbLongDate** | 1 | 使用系统区域设置指定的长日期格式显示日期。 |
| **vbShortDate** | 2 | 使用系统区域设置指定的短日期格式显示日期。 |
| **vbLongTime** | 3 | 使用系统区域设置指定的长时间格式显示时间。 |
| **vbShortTime** | 4 | 使用系统区域设置指定的短时间格式显示时间。 |
