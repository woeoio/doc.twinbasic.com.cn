# VbTriState

三态值，用于替代 **Boolean** 参数，以便保留"使用默认值"选项。常见于格式化函数，如 [**FormatNumber**](/official/Reference/VBA/Strings/FormatNumber)、[**FormatPercent**](/official/Reference/VBA/Strings/FormatPercent) 和 [**FormatCurrency**](/official/Reference/VBA/Strings/FormatCurrency)。

| 常量 | 值 | 描述 |
|------|-----|------|
| **vbTrue** | -1 | True。 |
| **vbFalse** | 0 | False。 |
| **vbUseDefault** | -2 | 使用系统默认设置。 |
