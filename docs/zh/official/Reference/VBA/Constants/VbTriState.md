# VbTriState

Three-state values used in place of **Boolean** arguments where a "use default" option must remain selectable. Common in formatting functions such as [**FormatNumber**](/official/Reference/VBA/Strings/FormatNumber), [**FormatPercent**](/official/Reference/VBA/Strings/FormatPercent), and [**FormatCurrency**](/official/Reference/VBA/Strings/FormatCurrency).

| Constant | Value | Description |
|----------|-------|-------------|
| **vbTrue** | -1 | True. |
| **vbFalse** | 0 | False. |
| **vbUseDefault** | -2 | Use the system default setting. |
