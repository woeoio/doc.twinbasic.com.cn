# VbCallType

**CallByName** 函数的 *calltype* 参数使用的过程调用类型。

| 常量 | 值 | 描述 |
|------|-----|------|
| **vbMethod** | 1 | 调用了一个方法。 |
| **vbGet** | 2 | **Property Get** 过程。 |
| **vbLet** | 4 | **Property Let** 过程。 |
| **vbSet** | 8 | **Property Set** 过程。 |
