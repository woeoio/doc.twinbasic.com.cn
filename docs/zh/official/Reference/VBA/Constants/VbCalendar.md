# VbCalendar

Calendar type values used by the [**Calendar**](/official/Reference/VBA/DateTime/Calendar) property.

| Constant | Value | Description |
|----------|-------|-------------|
| **vbCalGreg** | 0 | The Gregorian calendar. |
| **vbCalHijri** | 1 | The Hijri calendar. |
