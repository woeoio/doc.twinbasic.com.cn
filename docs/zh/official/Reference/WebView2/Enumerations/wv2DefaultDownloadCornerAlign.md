# wv2DefaultDownloadCornerAlign
将内置下载进度对话框锚定到 WebView2 控件的一个角落。镜像 `COREWEBVIEW2_DEFAULT_DOWNLOAD_DIALOG_CORNER_ALIGNMENT` 枚举。

| 常量 | 值 | 描述 |
|------|-----|------|
| **wv2CornerTopLeft** | 0 | 左上角。 |
| **wv2CornerTopRight** | 1 | 右上角。 |
| **wv2CornerBottomLeft** | 2 | 左下角。 |
| **wv2CornerBottomRight** | 3 | 右下角。 |
