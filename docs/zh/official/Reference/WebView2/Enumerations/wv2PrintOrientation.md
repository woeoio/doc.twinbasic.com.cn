# wv2PrintOrientation
将当前文档写入 PDF 文件时传递给 [**PrintToPdf**](/official/Reference/WebView2/WebView2/#printtopdf) 的页面方向。镜像 `COREWEBVIEW2_PRINT_ORIENTATION` 枚举。

| 常量 | 值 | 描述 |
|------|-----|------|
| **wv2PrintPortrait** | 0 | 默认——页面以长边垂直方向排列。 |
| **wv2PrintLandscape** | 1 | 页面以长边水平方向排列。 |
