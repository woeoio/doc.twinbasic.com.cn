# wv2PrintOrientation
Page orientation passed to [**PrintToPdf**](/official/Reference/WebView2/WebView2/#printtopdf) when writing the current document to a PDF file. Mirrors the `COREWEBVIEW2_PRINT_ORIENTATION` enumeration.

| Constant | Value | Description |
|----------|-------|-------------|
| **wv2PrintPortrait** | 0 | Default --- pages are laid out with the long side vertical. |
| **wv2PrintLandscape** | 1 | Pages are laid out with the long side horizontal. |
