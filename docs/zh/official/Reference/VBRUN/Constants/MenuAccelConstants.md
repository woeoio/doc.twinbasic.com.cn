# MenuAccelConstants

菜单项**Shortcut**属性的键盘快捷键代码，标识哪个组合键触发给定菜单命令。

## Ctrl + 字母

| 常量 | 值 | 说明 |
|----------|-------|-------------|
| **vbMenuAccelCtrlA** -- **vbMenuAccelCtrlZ** | 1 -- 26 | **Ctrl** + **A**到**Ctrl** + **Z**。 |

## 功能键

| 常量 | 值 | 说明 |
|----------|-------|-------------|
| **vbMenuAccelF1** -- **vbMenuAccelF9** | 27 -- 35 | **F1**到**F9**。 |
| **vbMenuAccelF11** | 36 | **F11**。 |
| **vbMenuAccelF12** | 37 | **F12**。 |

| 常量 | 值 | 说明 |
|----------|-------|-------------|

| **vbMenuAccelCtrlF11** | 47 | **Ctrl** + **F11**。 |
| **vbMenuAccelCtrlF12** | 48 | **Ctrl** + **F12**。 |
