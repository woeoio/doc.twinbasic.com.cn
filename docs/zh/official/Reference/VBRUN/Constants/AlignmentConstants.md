# AlignmentConstants

标签、文本框和选项按钮控件的**Alignment**属性的文本对齐值。

| 常量 | 值 | 说明 |
|----------|-------|-------------|
| **vbLeftJustify** | 0 | 文本左对齐。 |
| **vbRightJustify** | 1 | 文本右对齐。 |
| **vbCenter** | 2 | 文本居中。 |
