# AlignmentConstants

Text alignment values for the **Alignment** property of label, text box, and option button controls.

| Constant | Value | Description |
|----------|-------|-------------|
| **vbLeftJustify** | 0 | Text is left-justified. |
| **vbRightJustify** | 1 | Text is right-justified. |
| **vbCenter** | 2 | Text is centred. |
