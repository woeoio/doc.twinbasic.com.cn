# CheckBoxConstants

复选框控件的**Value**属性的状态值。

| 常量 | 值 | 说明 |
|----------|-------|-------------|
| **vbUnchecked** | 0 | 复选框未选中。 |
| **vbChecked** | 1 | 复选框已选中。 |
| **vbGrayed** | 2 | 复选框显示为不确定（灰色）状态。 |
