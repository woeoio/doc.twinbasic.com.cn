# DragOverConstants

控件**DragOver**事件的*State*参数中报告的状态值。

| 常量 | 值 | 说明 |
|----------|-------|-------------|
| **vbEnter** | 0 | 拖动源刚进入目标。 |
| **vbLeave** | 1 | 拖动源刚离开目标。 |
| **vbOver** | 2 | 拖动源正在目标上方移动。 |
