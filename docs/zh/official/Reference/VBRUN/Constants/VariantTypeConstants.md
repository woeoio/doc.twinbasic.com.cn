# VariantTypeConstants

遗留的DAO字段类型标签，为与极早期的Visual Basic/DAO代码兼容而保留。新代码应使用[**VbVarType**](/official/Reference/VBA/Constants/VbVarType)中的对应值。

| 常量 | 值 | 说明 |
|----------|-------|-------------|
| **vbVEmpty** | 0 | 空（未初始化）。 |
| **vbVNull** | 1 | **Null**。 |
| **vbVInteger** | 2 | **Integer**。 |
| **vbVLong** | 3 | **Long**。 |
| **vbVSingle** | 4 | 单精度浮点数。 |
| **vbVDouble** | 5 | 双精度浮点数。 |
| **vbVCurrency** | 6 | **Currency**。 |
| **vbVDate** | 7 | **Date**。 |
| **vbVString** | 8 | **String**。 |
