# OLEContainerActivateConstants

**OLE**容器控件**AutoActivate**属性的激活触发值。

| 常量 | 值 | 说明 |
|----------|-------|-------------|
| **vbOLE_ActivateManual** | 0 | 嵌入对象仅在调用**DoVerb**方法时激活。 |
| **vbOLE_ActivateGetFocus** | 1 | **OLE**容器获得焦点时激活对象。 |
| **vbOLE_ActivateDoubleclick** | 2 | 用户双击时激活对象。 |
| **vbOLE_ActivateAuto** | 3 | 根据注册的默认设置自动激活对象。 |
