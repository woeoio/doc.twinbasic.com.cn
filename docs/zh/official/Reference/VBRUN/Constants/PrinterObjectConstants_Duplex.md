# PrinterObjectConstants_Duplex

**Printer.Duplex**属性的双面模式值。标记为**\[MustBeQualified\]**，因此成员必须通过枚举名引用（`PrinterObjectConstants_Duplex.vbPRDPSimplex`）。

| 常量 | 值 | 说明 |
|----------|-------|-------------|
| **vbPRDPSimplex** | 1 | 仅单面打印。 |
| **vbPRDPHorizontal** | 2 | 双面打印，长边装订（书本式）。 |
| **vbPRDPVertical** | 3 | 双面打印，短边装订（日历式）。 |
