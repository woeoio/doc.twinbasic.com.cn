# LoadResConstants

**LoadResPicture**函数的*Format*参数的资源类型值。

| 常量 | 值 | 说明 |
|----------|-------|-------------|
| **vbResBitmap** | 0 | 加载位图资源。 |
| **vbResIcon** | 1 | 加载图标资源。 |
| **vbResCursor** | 2 | 加载光标资源。 |
| **vbResBitmapFromIcon** | 3 | 加载图标资源并转换为位图。*(twinBASIC新增)* |
