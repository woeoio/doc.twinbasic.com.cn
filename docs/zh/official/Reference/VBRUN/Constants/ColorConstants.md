# ColorConstants

常用命名RGB颜色值，适用于以**Long**或**OLE_COLOR**提供颜色的任何场合。数值遵循GDI字节顺序 --- `&H00BBGGRR`。

| 常量 | 值 | 说明 |
|----------|-------|-------------|
| **vbBlack** | 0 | 黑色。 |
| **vbRed** | 255 | 红色。 |
| **vbGreen** | 65280 | 绿色。 |
| **vbYellow** | 65535 | 黄色。 |
| **vbBlue** | 16711680 | 蓝色。 |
| **vbMagenta** | 16711935 | 品红色。 |
| **vbCyan** | 16776960 | 青色。 |
| **vbWhite** | 16777215 | 白色。 |
