# FormShowConstants

窗体**Show**方法的*Modal*参数的模态值。

| 常量 | 值 | 说明 |
|----------|-------|-------------|
| **vbModeless** | 0 | 窗体以非模态显示：调用代码立即继续，用户可与应用程序中的其他窗口交互。 |
| **vbModal** | 1 | 窗体以模态显示：调用在窗体关闭之前不返回，在此之前用户不能与应用程序中的其他窗口交互。 |
