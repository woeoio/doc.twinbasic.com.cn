# PrinterObjectConstants_PrintQuality

**Printer.PrintQuality**属性的打印质量值。标记为**\[MustBeQualified\]**，因此成员必须通过枚举名引用（`PrinterObjectConstants_PrintQuality.vbPRPQDraft`）。

| 常量 | 值 | 说明 |
|----------|-------|-------------|
| **vbPRPQDraft** | -1 | 草稿质量。 |
| **vbPRPQLow** | -2 | 低质量。 |
| **vbPRPQMedium** | -3 | 中等质量。 |
| **vbPRPQHigh** | -4 | 高质量。 |
