# DataBOFconstants

Data控件**BOFAction**属性的操作值，控制当用户移动到记录集开头之前时发生什么。

| 常量 | 值 | 说明 |
|----------|-------|-------------|
| **vbMoveFirst** | 0 | 移回第一条记录。 |
| **vbBOF** | 1 | 记录集定位在文件开头标记处；不允许继续向前导航。 |
