# OldLinkModeConstants

为与早期Visual Basic版本兼容而保留的旧式DDE链接模式值。新代码应使用[**LinkModeConstants**](/official/Reference/VBRUN/Constants/LinkModeConstants)。

| 常量 | 值 | 说明 |
|----------|-------|-------------|
| **vbHot** | 1 | 源数据更改时控件自动更新（"热"链接）。 |
| **vbServer** | 1 | 窗体作为DDE源。 |
| **vbCold** | 2 | 仅在显式请求时控件更新（"冷"链接）。 |
