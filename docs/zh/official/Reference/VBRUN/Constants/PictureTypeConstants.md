# PictureTypeConstants

Subtype values reported by the **Type** property of an **stdole.IPictureDisp**.

| Constant | Value | Description |
|----------|-------|-------------|
| **vbPicTypeNone** | 0 | The picture is empty. |
| **vbPicTypeBitmap** | 1 | A device-dependent or device-independent bitmap. |
| **vbPicTypeMetafile** | 2 | A Windows metafile. |
| **vbPicTypeIcon** | 3 | An icon. |
| **vbPicTypeEMetafile** | 4 | An enhanced metafile. |
