# PictureTypeConstants

**stdole.IPictureDisp**的**Type**属性报告的子类型值。

| 常量 | 值 | 说明 |
|----------|-------|-------------|
| **vbPicTypeNone** | 0 | 图片为空。 |
| **vbPicTypeBitmap** | 1 | 设备相关或设备无关位图。 |
| **vbPicTypeMetafile** | 2 | Windows元文件。 |
| **vbPicTypeIcon** | 3 | 图标。 |
| **vbPicTypeEMetafile** | 4 | 增强元文件。 |
