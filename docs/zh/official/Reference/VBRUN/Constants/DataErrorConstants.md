# DataErrorConstants

Data控件**Error**事件处理程序返回的响应值。

| 常量 | 值 | 说明 |
|----------|-------|-------------|
| **vbDataErrContinue** | 0 | 继续执行，如同未发生错误。 |
| **vbDataErrDisplay** | 1 | 显示标准错误对话框，让运行时处理错误。 |
