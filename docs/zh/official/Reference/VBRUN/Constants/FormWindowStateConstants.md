# FormWindowStateConstants

窗体**WindowState**属性的窗口状态值。

| 常量 | 值 | 说明 |
|----------|-------|-------------|
| **vbNormal** | 0 | 窗体以正常大小和位置显示。 |
| **vbMinimized** | 1 | 窗体最小化为图标。 |
| **vbMaximized** | 2 | 窗体最大化以填充屏幕（或其MDI父窗口）。 |
