# DrawStyleConstants

**DrawStyle**属性的线条样式值，控制使用**Line**和**Circle**绘制的线条外观。

| 常量 | 值 | 说明 |
|----------|-------|-------------|
| **vbSolid** | 0 | 实线（默认）。 |
| **vbDash** | 1 | 虚线。 |
| **vbDot** | 2 | 点线。 |
| **vbDashDot** | 3 | 点划线。 |
| **vbDashDotDot** | 4 | 双点划线。 |
| **vbInvisible** | 5 | 不绘制线条。 |
| **vbInsideSolid** | 6 | 完全在任何闭合形状边界内绘制的实线。 |
