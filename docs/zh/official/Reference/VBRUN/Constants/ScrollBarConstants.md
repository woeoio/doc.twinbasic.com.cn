# ScrollBarConstants

Values for the **ScrollBars** property of text-box, list-box, and similar controls, choosing which scrollbars are shown.

| Constant | Value | Description |
|----------|-------|-------------|
| **vbSBNone** | 0 | No scrollbars. |
| **vbHorizontal** | 1 | A horizontal scrollbar only. |
| **vbVertical** | 2 | A vertical scrollbar only. |
| **vbBoth** | 3 | Both scrollbars. |
