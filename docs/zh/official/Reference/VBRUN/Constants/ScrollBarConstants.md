# ScrollBarConstants

文本框、列表框及类似控件的**ScrollBars**属性值，选择显示哪些滚动条。

| 常量 | 值 | 说明 |
|----------|-------|-------------|
| **vbSBNone** | 0 | 无滚动条。 |
| **vbHorizontal** | 1 | 仅水平滚动条。 |
| **vbVertical** | 2 | 仅垂直滚动条。 |
| **vbBoth** | 3 | 水平和垂直滚动条。 |
