# HitResultConstants

**UserControl**的**HitTest**事件的返回值，告诉宿主所提供的点与控件的关系。

| 常量 | 值 | 说明 |
|----------|-------|-------------|
| **vbHitResultOutside** | 0 | 该点在控件的点击测试区域之外。 |
| **vbHitResultTransparent** | 1 | 该点在控件边界内但在透明区域；鼠标输入传递到后面的控件。 |
| **vbHitResultClose** | 2 | 该点靠近控件。 |
| **vbHitResultHit** | 3 | 该点在控件内，应视为命中。 |
