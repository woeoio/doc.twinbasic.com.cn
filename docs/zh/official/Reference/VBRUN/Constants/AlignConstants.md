# AlignConstants

窗体和控件 --- 图片框、数据控件和工具栏 --- 的**Align**属性值，将控件锚定到其容器的某一边缘。

| 常量 | 值 | 说明 |
|----------|-------|-------------|
| **vbAlignNone** | 0 | 大小和位置在设计时或代码中设置。 |
| **vbAlignTop** | 1 | 控件锚定到容器的顶部边缘。 |
| **vbAlignBottom** | 2 | 控件锚定到容器的底部边缘。 |
| **vbAlignLeft** | 3 | 控件锚定到容器的左侧边缘。 |
| **vbAlignRight** | 4 | 控件锚定到容器的右侧边缘。 |
