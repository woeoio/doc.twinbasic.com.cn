# ShapeConstants

**Shape**控件的**Shape**属性的几何形状值。

| 常量 | 值 | 说明 |
|----------|-------|-------------|
| **vbShapeRectangle** | 0 | 矩形。 |
| **vbShapeSquare** | 1 | 正方形。 |
| **vbShapeOval** | 2 | 椭圆。 |
| **vbShapeCircle** | 3 | 圆形。 |
| **vbShapeRoundedRectangle** | 4 | 圆角矩形。 |
| **vbShapeRoundedSquare** | 5 | 圆角正方形。 |
| **vbShapeStar** | 6 | 星形。 |
| **vbShapeArrowLeft** | 7 | 左箭头。 |
| **vbShapeArrowRight** | 8 | 右箭头。 |
| **vbShapeArrowUp** | 9 | 上箭头。 |
| **vbShapeArrowDown** | 10 | 下箭头。 |
