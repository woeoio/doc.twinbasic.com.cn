# ComboBoxConstants

组合框控件的**Style**属性的样式值。

| 常量 | 值 | 说明 |
|----------|-------|-------------|
| **vbComboDropdown** | 0 | 下拉组合框：用户可以输入值或从列表中选择。 |
| **vbComboSimple** | 1 | 简单组合框：列表始终可见，用户也可以输入值。 |
| **vbComboDropdownList** | 2 | 下拉列表：用户必须从列表中选择值。 |
