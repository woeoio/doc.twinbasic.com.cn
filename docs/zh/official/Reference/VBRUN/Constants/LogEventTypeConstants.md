# LogEventTypeConstants

Severity values for the *EventType* argument of the **LogEvent** method.

| Constant | Value | Description |
|----------|-------|-------------|
| **vbLogEventTypeError** | 1 | The entry describes an error. |
| **vbLogEventTypeWarning** | 2 | The entry describes a warning. |
| **vbLogEventTypeInformation** | 4 | The entry is informational. |
