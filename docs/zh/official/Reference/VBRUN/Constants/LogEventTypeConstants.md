# LogEventTypeConstants

**LogEvent**方法的*EventType*参数的严重级别值。

| 常量 | 值 | 说明 |
|----------|-------|-------------|
| **vbLogEventTypeError** | 1 | 条目描述一个错误。 |
| **vbLogEventTypeWarning** | 2 | 条目描述一个警告。 |
| **vbLogEventTypeInformation** | 4 | 条目为信息性内容。 |
