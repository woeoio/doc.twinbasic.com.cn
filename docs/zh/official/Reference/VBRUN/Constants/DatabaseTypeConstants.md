# DatabaseTypeConstants

Data控件**DefaultType**属性的引擎值，选择控件应使用的数据库后端。

| 常量 | 值 | 说明 |
|----------|-------|-------------|
| **vbUseODBC** | 1 | 通过ODBC连接。 |
| **vbUseJet** | 2 | 通过Jet(Access)引擎连接。 |
| **vbUseACE** | 3 | 通过ACE(Access 2007+)引擎连接。*(twinBASIC新增)* |
