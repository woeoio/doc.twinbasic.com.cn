# MultiSelectConstants

列表框控件的**MultiSelect**属性的多选模式值。

| 常量 | 值 | 说明 |
|----------|-------|-------------|
| **vbMultiSelectNone** | 0 | 一次只能选择一项。 |
| **vbMultiSelectSimple** | 1 | 每次点击切换所点击项的选择状态。 |
| **vbMultiSelectExtended** | 2 | 用户可用**Shift**+点击选择范围，**Ctrl**+点击切换单项。 |
