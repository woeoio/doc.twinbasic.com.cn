# OLEContainerTypesAllowedConstants

**OLE**容器控件**OLETypeAllowed**属性的对象类型过滤值，限制容器接受哪些类型的对象。

| 常量 | 值 | 说明 |
|----------|-------|-------------|
| **vbOLE_Linked** | 0 | 仅允许链接对象。 |
| **vbOLE_Embedded** | 1 | 仅允许嵌入对象。 |
| **vbOLE_Either** | 2 | 允许链接或嵌入对象。 |
