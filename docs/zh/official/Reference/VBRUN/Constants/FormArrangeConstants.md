# FormArrangeConstants

MDI父窗体**Arrange**方法的排列模式，控制其子窗口的布局方式。

| 常量 | 值 | 说明 |
|----------|-------|-------------|
| **vbCascade** | 0 | 层叠排列打开的子窗口。 |
| **vbTileHorizontal** | 1 | 水平平铺子窗口。 |
| **vbTileVertical** | 2 | 垂直平铺子窗口。 |
| **vbArrangeIcons** | 3 | 沿MDI父窗口底部排列最小化子窗口的图标。 |
