# AlignmentConstantsNoCenter

外观不包括居中选项的属性的文本对齐值 --- 例如滚动条对齐值或仅支持左/右对齐的文本字段。

| 常量 | 值 | 说明 |
|----------|-------|-------------|
| **tbLeftJustify** | 0 | 文本左对齐。 |
| **tbRightJustify** | 1 | 文本右对齐。 |
