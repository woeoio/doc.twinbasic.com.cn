# PrinterObjectConstants_ColorMode

**Printer.ColorMode**属性的颜色模式值。标记为**\[MustBeQualified\]**，因此成员必须通过枚举名引用（`PrinterObjectConstants_ColorMode.vbPRCMColor`）。

| 常量 | 值 | 说明 |
|----------|-------|-------------|
| **vbPRCMMonochrome** | 1 | 单色打印。 |
| **vbPRCMColor** | 2 | 彩色打印。 |
