# BorderStyleConstants

**Shape**和**Line**控件的**BorderStyle**属性的线条样式值。

| 常量 | 值 | 说明 |
|----------|-------|-------------|
| **vbTransparent** | 0 | 不绘制边框。 |
| **vbBSSolid** | 1 | 实线边框。 |
| **vbBSDash** | 2 | 虚线边框。 |
| **vbBSDot** | 3 | 点线边框。 |
| **vbBSDashDot** | 4 | 点划线边框。 |
| **vbBSDashDotDot** | 5 | 双点划线边框。 |
| **vbBSInsideSolid** | 6 | 完全在形状边界内绘制的实线边框。 |
