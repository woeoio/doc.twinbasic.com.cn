# ButtonConstants

支持可选图形（基于图像）外观的命令按钮的样式值。

| 常量 | 值 | 说明 |
|----------|-------|-------------|
| **vbButtonStandard** | 0 | 按钮作为标准系统按钮绘制。 |
| **vbButtonGraphical** | 1 | 按钮作为可显示图片的图形按钮绘制。仅在启用**FEATURE_GRAPHICAL_BUTTONS**功能时可用。 |
