# DragModeConstants

控件**DragMode**属性的值，控制拖动是自动开始（用户点击并拖动时）还是仅在显式调用**Drag**时开始。

| 常量 | 值 | 说明 |
|----------|-------|-------------|
| **vbManual** | 0 | 控件在代码调用**Drag**之前不可拖动。 |
| **vbAutomatic** | 1 | 用户在控件上按下鼠标按钮时自动开始拖动。 |
