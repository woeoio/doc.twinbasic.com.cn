# VerticalAlignmentConstants

单元格样式控件等属性的垂直文本对齐值，如 **VerticalAlignment** 属性。

| 常量 | 值 | 说明 |
|----------|-------|-------------|
| **vbVerticalAlignTop** | 0 | 文本顶部对齐。 |
| **vbVerticalAlignMiddle** | 1 | 文本垂直居中。 |
| **vbVerticalAlignBottom** | 2 | 文本底部对齐。 |
