# VerticalAlignmentConstants

Vertical text alignment values for properties such as the **VerticalAlignment** of cell-style controls.

| Constant | Value | Description |
|----------|-------|-------------|
| **vbVerticalAlignTop** | 0 | Text is aligned to the top. |
| **vbVerticalAlignMiddle** | 1 | Text is centred vertically. |
| **vbVerticalAlignBottom** | 2 | Text is aligned to the bottom. |
