# LoadPictureColorConstants

**LoadPicture**的*vbLPColor*参数的颜色深度选择器。

| 常量 | 值 | 说明 |
|----------|-------|-------------|
| **vbLPDefault** | 0 | 使用源图像的本机颜色深度。 |
| **vbLPMonochrome** | 1 | 加载为单色（1位）图像。 |
| **vbLPVGAColor** | 2 | 加载为16色（4位）图像。 |
| **vbLPColor** | 3 | 加载为全彩图像。 |
