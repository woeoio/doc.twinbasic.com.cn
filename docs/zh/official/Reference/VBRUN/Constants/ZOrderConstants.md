# ZOrderConstants

窗体和控件 **ZOrder** 方法的层叠位置选择器。

| 常量 | 值 | 说明 |
|----------|-------|-------------|
| **vbBringToFront** | 0 | 将对象移到z序的最前面，使其绘制在同辈对象之上。 |
| **vbSendToBack** | 1 | 将对象移到z序的最后面，使同辈对象绘制在其之上。 |
