# ZOrderConstants

Position selectors for the **ZOrder** method of forms and controls.

| Constant | Value | Description |
|----------|-------|-------------|
| **vbBringToFront** | 0 | Move the object to the front of its z-order so it is drawn on top of its siblings. |
| **vbSendToBack** | 1 | Move the object to the back of its z-order so its siblings are drawn on top of it. |
