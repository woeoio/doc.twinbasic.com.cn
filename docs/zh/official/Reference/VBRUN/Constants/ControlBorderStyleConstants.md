# ControlBorderStyleConstants

文本框、图片框和标签等内在控件的**BorderStyle**属性的边框样式值。

| 常量 | 值 | 说明 |
|----------|-------|-------------|
| **vbNoBorder** | 0 | 不绘制边框。 |
| **vbFixedSingleBorder** | 1 | 固定单线边框，不可调整大小。 |
