# OLEContainerUpdateOptionsConstants

**OLE**容器控件**UpdateOptions**属性的更新模式值，控制链接对象如何与其源保持同步。

| 常量 | 值 | 说明 |
|----------|-------|-------------|
| **vbOLE_UpdateAutomatic** | 0 | 源数据更改时自动更新对象。 |
| **vbOLE_UpdateFrozen** | 1 | 更新已暂停。 |
| **vbOLE_UpdateManual** | 2 | 仅在调用**Update**时更新对象。 |
