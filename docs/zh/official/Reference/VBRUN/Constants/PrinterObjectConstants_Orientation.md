# PrinterObjectConstants_Orientation

**Printer.Orientation**属性的纸张方向值。标记为**\[MustBeQualified\]**，因此成员必须通过枚举名引用（`PrinterObjectConstants_Orientation.vbPRORPortrait`）。

| 常量 | 值 | 说明 |
|----------|-------|-------------|
| **vbPRORPortrait** | 1 | 纵向。 |
| **vbPRORLandscape** | 2 | 横向。 |
