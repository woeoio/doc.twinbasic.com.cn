# NegotiatePositionConstants

菜单项**NegotiatePosition**属性的位置值，控制OLE就地活动对象协商宿主菜单栏时菜单出现在何处。

| 常量 | 值 | 说明 |
|----------|-------|-------------|
| **vbNegotiatePositionNone** | 0 | 就地激活期间菜单被隐藏。 |
| **vbNegotiatePositionLeft** | 1 | 菜单放置在协商菜单栏的左侧组。 |
| **vbNegotiatePositionMiddle** | 2 | 菜单放置在中间组。 |
| **vbNegotiatePositionRight** | 3 | 菜单放置在右侧组。 |
