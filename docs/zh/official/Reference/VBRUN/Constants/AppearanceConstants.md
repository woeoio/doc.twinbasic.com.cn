# AppearanceConstants

窗体和控件的**Appearance**属性的绘图样式值。

| 常量 | 值 | 说明 |
|----------|-------|-------------|
| **vbAppearFlat** | 0 | 控件不带三维效果绘制。 |
| **vbAppear3d** | 1 | 控件边框和边缘带三维阴影绘制。 |
