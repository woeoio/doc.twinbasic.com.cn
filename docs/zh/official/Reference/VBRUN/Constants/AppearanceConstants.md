# AppearanceConstants

Drawing-style values for the **Appearance** property of forms and controls.

| Constant | Value | Description |
|----------|-------|-------------|
| **vbAppearFlat** | 0 | The control is drawn without 3-D effects. |
| **vbAppear3d** | 1 | The control is drawn with 3-D shading on its borders and edges. |
