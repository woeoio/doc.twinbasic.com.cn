# FormBorderStyleConstants

窗体**BorderStyle**属性的边框和框架样式值，选择窗体具有哪种窗口装饰以及用户是否可以调整其大小。

| 常量 | 值 | 说明 |
|----------|-------|-------------|
| **vbBSNone** | 0 | 窗体无边框、标题栏或系统菜单。 |
| **vbFixedSingle** | 1 | 固定单线边框，不可调整大小，带正常标题栏。 |
| **vbSizable** | 2 | 可调整大小的边框，带正常标题栏（窗体默认）。 |
| **vbFixedDialog** | 3 | 对话框样式的固定边框。 |
| **vbFixedToolWindow** | 4 | 不可调整大小的工具窗口边框，带小标题栏。 |
| **vbSizableToolWindow** | 5 | 可调整大小的工具窗口边框，带小标题栏。 |
| **vbSizableNoTitleBar** | 6 | 可调整大小的边框，无标题栏。*(twinBASIC新增)* |
| **vbSizableToolWindowNoTitleBar** | 7 | 可调整大小的工具窗口边框，无标题栏。*(twinBASIC新增)* |
