# StartUpPositionConstants

窗体 **StartUpPosition** 属性的初始位置值，决定窗体首次出现的位置。

| 常量 | 值 | 说明 |
|----------|-------|-------------|
| **vbStartUpManual** | 0 | 通过 **Top** 和 **Left** 属性显式设置位置。 |
| **vbStartUpOwner** | 1 | 窗体在其所有者上居中。 |
| **vbStartUpScreen** | 2 | 窗体在屏幕上居中。 |
| **vbStartUpWindowsDefault** | 3 | 窗体位于Windows选择的默认位置。 |
