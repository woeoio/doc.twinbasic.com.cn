# MouseButtonConstants

**MouseDown**、**MouseUp**和**MouseMove**等鼠标事件的*Button*参数的位标志，标识按下了哪些按钮。使用`Or`组合以测试多个按钮。

| 常量 | 值 | 说明 |
|----------|-------|-------------|
| **vbLeftButton** | 1 | 鼠标左键。 |
| **vbRightButton** | 2 | 鼠标右键。 |
| **vbMiddleButton** | 4 | 鼠标中键。 |
