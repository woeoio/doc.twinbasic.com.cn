# DragConstants

Action values for the **Drag** method of a control, controlling the start, end, or cancellation of a manual drag.

| Constant | Value | Description |
|----------|-------|-------------|
| **vbCancel** | 0 | Cancel the drag operation in progress. |
| **vbBeginDrag** | 1 | Begin dragging the control. |
| **vbEndDrag** | 2 | Drop the control at the current location. |
