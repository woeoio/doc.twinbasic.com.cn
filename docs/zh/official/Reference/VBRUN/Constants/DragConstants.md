# DragConstants

控件**Drag**方法的操作值，控制手动拖动的开始、结束或取消。

| 常量 | 值 | 说明 |
|----------|-------|-------------|
| **vbCancel** | 0 | 取消正在进行的拖动操作。 |
| **vbBeginDrag** | 1 | 开始拖动控件。 |
| **vbEndDrag** | 2 | 在当前位置放下控件。 |
