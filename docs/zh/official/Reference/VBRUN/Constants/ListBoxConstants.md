# ListBoxConstants

列表框控件的**Style**属性的样式值。

| 常量 | 值 | 说明 |
|----------|-------|-------------|
| **vbListBoxStandard** | 0 | 标准列表框：每项为字符串。 |
| **vbListBoxCheckbox** | 1 | 每项显示复选框，用户可以独立于选择切换。 |
| **vbListBoxColorSwatch** | 2 | 每项在文本旁显示色块。 |
