# ParentControlsType

[**ParentControls**](/official/Reference/VBRUN/ParentControls/)集合的包装模式，控制每个项目是在其宿主**Extender**中包装返回还是作为裸控件返回。

| 常量 | 值 | 说明 |
|----------|-------|-------------|
| **vbNoExtender** | 0 | 项目作为裸控件返回，不带宿主的**Extender**包装。 |
| **vbExtender** | 1 | 项目在宿主的**Extender**中包装返回，暴露容器提供的布局属性。这是默认值。 |
