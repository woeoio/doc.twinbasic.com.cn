# ShiftConstants

鼠标和键盘事件*Shift*参数的位标志，标识按下了哪些修饰键。使用`Or`组合以测试多个修饰键。

| 常量 | 值 | 说明 |
|----------|-------|-------------|
| **vbShiftMask** | 1 | 按下了**Shift**。 |
| **vbCtrlMask** | 2 | 按下了**Ctrl**。 |
| **vbAltMask** | 4 | 按下了**Alt**。 |
