# BackFillStyleConstants

控件背景填充是不透明还是透明。

| 常量 | 值 | 说明 |
|----------|-------|-------------|
| **vbBFTransparent** | 0 | 控件背景透明 --- 后面的内容可见。 |
| **vbBFOpaque** | 1 | 控件背景用其**BackColor**纯色填充。 |
