# OrientationConstants
由 [**Slider.Orientation**](/official/Reference/WinNativeCommonCtls/Slider#orientation) 和 [**UpDown.Orientation**](/official/Reference/WinNativeCommonCtls/UpDown#orientation) 共享的水平/垂直枚举。

| 成员                          | 值 | 描述           |
|---------------------------------|-------|-----------------------|
| **ccOrientationHorizontal** | 0 | 水平方向。 |
| **ccOrientationVertical**     | 1 | 垂直方向。   |
