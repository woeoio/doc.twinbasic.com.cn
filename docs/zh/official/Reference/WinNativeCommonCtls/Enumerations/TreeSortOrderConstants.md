# TreeSortOrderConstants
The sort direction enumeration used by [**TreeView.SortOrder**](/official/Reference/WinNativeCommonCtls/TreeView/#sortorder) and [**Node.SortOrder**](/official/Reference/WinNativeCommonCtls/TreeView/Node#sortorder).

| Member                | Value | Description                       |
|-----------------------|-------|-----------------------------------|
| **tvwAscending**   | 0 | Sort A-to-Z.                  |
| **tvwDescending** | 1 | Sort Z-to-A.                  |
