# TreeSortOrderConstants
由 [**TreeView.SortOrder**](/official/Reference/WinNativeCommonCtls/TreeView/#sortorder) 和 [**Node.SortOrder**](/official/Reference/WinNativeCommonCtls/TreeView/Node#sortorder) 使用的排序方向枚举。

| 成员                | 值 | 描述                       |
|-----------------------|-------|-----------------------------------|
| **tvwAscending**   | 0 | 升序排列（A到Z）。                  |
| **tvwDescending** | 1 | 降序排列（Z到A）。                  |
