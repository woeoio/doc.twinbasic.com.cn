# 监视

当没有打开项目时，此处将为空。

![监视](Images/Watches.png "监视")

一旦打开项目，将显示其他可用按钮。

![监视](Images/Watches_1.png "监视")

如果要添加新的监视，请点击![添加](Images/Add.png "添加")按钮并输入您的"要监视的表达式"

![监视](Images/Watches_2.png "监视")

您可以使用清除按钮![清除](Images/Clear.png "清除")移除任何监视项
