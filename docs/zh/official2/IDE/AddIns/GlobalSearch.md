## 全局搜索

此插件随 twinBASIC IDE 提供。

最新版本
: v1.0.0.0

开发者
: twinBASIC

全局搜索插件将包含一个[工具栏](../Project/Toolbar)项目。

![全局搜索（工具栏）](Images/Toolbar_GlobalSearch.png "全局搜索（工具栏）")

![全局搜索](Images/GlobalSearch.png "全局搜索")

选项

- 在包中
- 匹配大小写
- 全词匹配
- 排除注释

在文本字段中输入搜索词，即 Button1，将返回匹配列表。

![全局搜索](Images/GlobalSearch_2.png "全局搜索")
