# 最近使用

如果您没有打开任何项目，或者已移除所有项目，则此选项卡将为空白。

![最近使用](Images/New_Project_Recent_1.png "最近使用")

将显示最近项目的列表，根据列表中的数量自动调整大小。

![最近使用](Images/New_Project_Recent_2.png "最近使用")

_已移除的路径_

点击X从列表中移除。
