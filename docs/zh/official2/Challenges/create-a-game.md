# 🎮 twinBASIC 月度挑战 #2 - 二月

**创建游戏**

使用 twinBASIC 构建**您喜欢的任何游戏**。

这可以是一个简单的纸牌游戏、街机游戏、益智游戏，或者更具实验性的作品。鼓励创意发挥 - 没有"正确"的类型或风格。

## 📦 提交规则

- 使用 twinBASIC 构建
- 必须提供完整源代码，但许可证选择不受限制
- 提交必须为*单个* `.twinproj` 文件（如有必要，允许外部图像和音乐资源文件）
- 生成**单个 Windows EXE 可执行文件**
- 能在**Windows 10 及更高版本**上运行
- 游戏可以是窗口模式或全屏模式
- 音乐是可选的
- ❌ 不能是现有 VB6 游戏的直接或近似移植

## 🎵 加分项

- 包含音乐或音效
- 包含控制器支持（例如 XInput）
- 使用**GDI+ 包** ⁠[GDI+ 包](https://discord.com/channels/927638153546829845/1460777854714515728)
- 使用**OpenGL** ⁠[twinBASIC + WinDevLib OpenGL De…](https://discord.com/channels/927638153546829845/1464785863702610053)
- 巧妙或高效的渲染技术
- 使用较新的 twinBASIC 功能（例如委托、泛型）
- 清晰的架构和良好记录的代码
- 精美的 UI、UX 或游戏手感
- 有趣的技术技巧（碰撞检测、AI 等）

## 🎁 奖品

## 🏆 评审

参赛作品将在多个类别中进行评审，包括：

- 原创性和创造力
- 技术执行
- 性能
- 视觉呈现
- 代码质量和结构
- 整体精细度和趣味性

twinBASIC 团队可自行决定授予加分。
