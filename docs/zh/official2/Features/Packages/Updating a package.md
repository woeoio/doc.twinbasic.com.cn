# 更新包

当您加载项目时，如果项目中的包在 TWINSERV 上有更新版本，编译器将通知您：

![image](Images/db4636f6-d988-4e31-94a2-c4c170418e81.png)


如果您发现 TWINSERV 上有更新的包可用，您必须首先通过取消选择从项目中删除旧包。打开设置到引用并取消勾选框。然后系统将提示您从文件系统中删除它：

![415937809-87a11bc3-9a9c-4551-86c2-69d206d95087](Images/a1331a0e-3ba3-45cf-8dc3-2e24f0fa1fe6.png)
<br/>
<br/>
<br/>

选择"删除它"。

然后转到可用包选项卡并勾选最新版本的框，在下载完成后（某些包可能有几 MB，可能需要几秒钟），保存更改。在调试控制台中，您首先会看到

`[PACKAGES] 正在从在线数据库下载包'{1FCDB98D-617D-4995-9736-2ED0E4746A10}/8/7/0/498'... `

然后完成并准备好保存，当出现第二条消息说

`[PACKAGES] 正在从在线数据库下载包'{1FCDB98D-617D-4995-9736-2ED0E4746A10}/8/7/0/498'... [完成]`

时。它也会从复选框旋转变为条目移动到顶部（内置包下方），前面加上`[已导入]`。

如果保存后没有自动重新启动编译器，请重新启动，但通常会。

**注意：**将来会有一个简单的更新选项。请注意这一变化。
