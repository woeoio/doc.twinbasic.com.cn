# TreeLabelEditConstants
Controls when inline label editing is triggered on a [**TreeView**](/en/official/Reference/WinNativeCommonCtls/TreeView/). Used by [**TreeView.LabelEdit**](/en/official/Reference/WinNativeCommonCtls/TreeView/#labeledit).

| Member               | Value | Description                                                                       |
|----------------------|-------|-----------------------------------------------------------------------------------|
| **tvwAutomatic** | 0 | Clicking an already-selected node opens the inline editor (after a short pause). |
| **tvwManual**       | 1 | Only programmatic [**StartLabelEdit**](/en/official/Reference/WinNativeCommonCtls/TreeView/#startlabeledit) calls open the editor. |
| **tvwDisabled**   | 2 | Label editing is disabled.                                                       |
