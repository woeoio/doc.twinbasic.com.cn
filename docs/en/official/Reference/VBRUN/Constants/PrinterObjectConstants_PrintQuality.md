# PrinterObjectConstants_PrintQuality

Print-quality values for the **Printer.PrintQuality** property. Tagged **\[MustBeQualified\]**, so members must be referenced through the enum name (`PrinterObjectConstants_PrintQuality.vbPRPQDraft`).

| Constant | Value | Description |
|----------|-------|-------------|
| **vbPRPQDraft** | -1 | Draft quality. |
| **vbPRPQLow** | -2 | Low quality. |
| **vbPRPQMedium** | -3 | Medium quality. |
| **vbPRPQHigh** | -4 | High quality. |
