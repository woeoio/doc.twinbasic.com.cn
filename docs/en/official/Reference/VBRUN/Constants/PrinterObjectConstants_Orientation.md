# PrinterObjectConstants_Orientation

Paper-orientation values for the **Printer.Orientation** property. Tagged **\[MustBeQualified\]**, so members must be referenced through the enum name (`PrinterObjectConstants_Orientation.vbPRORPortrait`).

| Constant | Value | Description |
|----------|-------|-------------|
| **vbPRORPortrait** | 1 | Portrait orientation. |
| **vbPRORLandscape** | 2 | Landscape orientation. |
