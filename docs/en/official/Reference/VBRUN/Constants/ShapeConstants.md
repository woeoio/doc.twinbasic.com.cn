# ShapeConstants

Geometric-shape values for the **Shape** property of the **Shape** control.

| Constant | Value | Description |
|----------|-------|-------------|
| **vbShapeRectangle** | 0 | Rectangle. |
| **vbShapeSquare** | 1 | Square. |
| **vbShapeOval** | 2 | Oval. |
| **vbShapeCircle** | 3 | Circle. |
| **vbShapeRoundedRectangle** | 4 | Rounded rectangle. |
| **vbShapeRoundedSquare** | 5 | Rounded square. |
| **vbShapeStar** | 6 | Star. |
| **vbShapeArrowLeft** | 7 | Arrow pointing left. |
| **vbShapeArrowRight** | 8 | Arrow pointing right. |
| **vbShapeArrowUp** | 9 | Arrow pointing up. |
| **vbShapeArrowDown** | 10 | Arrow pointing down. |
