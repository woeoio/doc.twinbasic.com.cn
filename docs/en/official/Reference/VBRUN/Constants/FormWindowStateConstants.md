# FormWindowStateConstants

Window-state values for the **WindowState** property of a form.

| Constant | Value | Description |
|----------|-------|-------------|
| **vbNormal** | 0 | The form is shown at its normal size and position. |
| **vbMinimized** | 1 | The form is minimised to an icon. |
| **vbMaximized** | 2 | The form is maximised to fill the screen (or its MDI parent). |
