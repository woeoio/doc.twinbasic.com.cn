# ControlBorderStyleConstants

Border-style values for the **BorderStyle** property of intrinsic controls such as text boxes, picture boxes, and labels.

| Constant | Value | Description |
|----------|-------|-------------|
| **vbNoBorder** | 0 | No border is drawn. |
| **vbFixedSingleBorder** | 1 | A single, non-resizable border. |
