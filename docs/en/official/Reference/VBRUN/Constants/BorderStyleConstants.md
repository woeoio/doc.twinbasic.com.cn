# BorderStyleConstants

Line-style values for the **BorderStyle** property of **Shape** and **Line** controls.

| Constant | Value | Description |
|----------|-------|-------------|
| **vbTransparent** | 0 | No border is drawn. |
| **vbBSSolid** | 1 | A solid border. |
| **vbBSDash** | 2 | A dashed border. |
| **vbBSDot** | 3 | A dotted border. |
| **vbBSDashDot** | 4 | A dash-dot border. |
| **vbBSDashDotDot** | 5 | A dash-dot-dot border. |
| **vbBSInsideSolid** | 6 | A solid border drawn entirely within the shape's bounds. |
