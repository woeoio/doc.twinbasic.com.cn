# CheckBoxConstants

State values for the **Value** property of a check-box control.

| Constant | Value | Description |
|----------|-------|-------------|
| **vbUnchecked** | 0 | The check box is cleared. |
| **vbChecked** | 1 | The check box is selected. |
| **vbGrayed** | 2 | The check box is shown in an indeterminate (gray) state. |
