# ColorConstants

Common named RGB colour values, suitable wherever a colour is supplied as a **Long** or **OLE_COLOR**. The numeric values follow the GDI byte order --- `&H00BBGGRR`.

| Constant | Value | Description |
|----------|-------|-------------|
| **vbBlack** | 0 | Black. |
| **vbRed** | 255 | Red. |
| **vbGreen** | 65280 | Green. |
| **vbYellow** | 65535 | Yellow. |
| **vbBlue** | 16711680 | Blue. |
| **vbMagenta** | 16711935 | Magenta. |
| **vbCyan** | 16776960 | Cyan. |
| **vbWhite** | 16777215 | White. |
